# GHMultiMonitor — Features

Spreads Grey Hack's in-game desktop across your extra monitors, so windows, icons, menus and dialogs
work on every screen the way they do on the main one. Everything happens on your own screen; the mod
never sends anything of its own to the server.

Status key:  tested in-game ·  built, awaiting test

## Extra monitors
-  Drag any window past the edge of your main screen onto another monitor, and back again
-  Press F9 to choose which monitors to use. Turning one on works immediately; turning one off takes
  effect the next time you start the game
-  While the F9 menu is open, each monitor shows its number so you can tell which is which
-  Your desktop wallpaper is shown on every extra monitor
-  Monitors of different sizes and resolutions work side by side
-  Windows can't get lost: one that would end up under the top bar or off the screen is nudged back
  so you can always grab it, and a "Bring all windows to main screen" button is there if you need it
-  Extra monitors stay dark during the boot-up and OS-install screens
-  Keeps the game in borderless fullscreen when you turn on extra monitors (can be turned off)
-  Asks which monitors to use the first time you launch, then remembers your choice

## Window snapping
-  Windows-style snapping: drag a window against a screen edge for a half, against the top to
  maximize, or into a corner for a quarter
-  A preview shows where the window will land before you let go
-  Works on every monitor, and on a single monitor too
-  Snapped windows never sit under the taskbar or top bar
-  Dragging a snapped window away gives it back its original size
-  Resizing a window by its edge never triggers a snap
-  Adjustable from the F9 menu: how close to the edge counts, how big the corners are, and how long
  you hold before the preview appears. The snap areas light up on every monitor while the menu is open,
  and a button resets everything to the defaults
-  Can be turned off entirely

## Remembered window positions
-  Windows reopen where you last put them, on the monitor you left them on
-  A second copy of an app won't open on top of the first
-  Windows the game places itself (like Properties) open in the middle of the monitor you're using
-  Can be turned off from the F9 menu; your saved positions are kept for if you turn it back on
-  "Forget saved window positions" button clears them all

## Desktop icons on other monitors
-  Every extra monitor has its own icon area, laid out on the same grid as the main desktop
-  Drop a file from any window onto an extra monitor's desktop and its icon appears there
-  Drag a desktop icon from one monitor to another and drop it where you like. Drop it back on the main
  desktop and it returns to the main grid
-  "Align to Grid" tidies the icons on every monitor
-  Icons stay on the monitor you put them on between launches
-  Icons on extra monitors change colour along with the rest of the desktop when you switch theme
-  Opening, right-clicking, renaming and deleting icons that live on another monitor

## On every monitor
-  Right-click menus work everywhere: files and folders, text (Notepad, web pages, the Browser's
  address bar), the Terminal, and the desktop itself. They open at your cursor on the monitor you clicked
-  Web pages in the Browser can be used on any monitor
-  File Explorer folders and files can be browsed and opened on any monitor
-  Text selection works on any monitor
-  Dialogs open on the same monitor as the app that asked for them, centered over it: the Save Program
  window, "Copying file...", and "Login to a different email account" in the Mail client
-  Drag files between windows from any monitor, or drop them on an extra monitor's desktop to copy
  them there
-  "Center window" centers a window on the monitor it's on

## Settings
-  Everything is set from the F9 menu and remembered between launches: which monitors to use, snapping,
  remembering window positions, and the buttons to bring windows back or forget saved positions
